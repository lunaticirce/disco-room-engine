# 世界时钟

每个存档保存 `day`（天数）、`minute`（分钟）和内部的 `second` 余量，其中 minute 归一化到 `0..1439`、second 归一化到 `0..59`。玩家界面仍显示到分钟；对话条件和场景条件读到的是同一个时钟。

- 每个真正说出或听到的对白框推进 23 秒。首次经过的节点只结算一次，因此重复输入 `beat` 不会偷走时间；玩家主动再次选择旧对白时会重新结算。
- `PassTime()` 每调用一次推进 15 分钟。
- `LetterSleep()` 推进到次日上午 08:00。
- 场景交互点可以用 `advance: "morning"`、`advance: "night"`，或一个数值分钟增量。

重复遍历只会重放那些有明确重复语义的用户脚本动词。这样玩家可以刻意再次等待，而不会把该节点上的每一条剧情变更都重新触发一遍。
