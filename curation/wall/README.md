# 记录墙

记录墙是这间房"怎么住进去"的那一半。`curation/` 给你一张可以走的世界地图；墙是你把它变成自己经历的方式——一拍一拍记下来，连成一张只属于这个侦探的知识网。

它不是引擎的一部分（引擎只管存档和世界状态），也不绑死某个 profile。**你原创写下的记录归你；引用的原作内容仍归原权利人，不由本项目许可。**

## 为什么记

对话图太大。"扫遍空间往前冲"和"每拍停下来、说清我看到什么、为什么这么选"是两种不同的玩法。墙的纪律逼出后一种——让图遍历变成真正的游玩。

## 每拍三层（编年的脊梁）

每一拍（或每个场景）在 `编年/` 开一页，至少这三层：

1. **原文出处** —— 默认只记 conv / node（出处，不抄台词）。
2. **我看到的世界** —— 这双眼睛看到的。
3. **我怎么选、为什么** —— 你的判断、内心声音。

有人陪玩，把同行者每拍的话也留进墙。

## 关于引用原作台词

默认只记 conv / node。如果你确实想引用一句原作台词，要明白：它仍归原权利人——不是"一行就安全"，也不因为写进你的墙就变成你的。能不引就不引；非引不可，越短越好，并清楚标明出处。

## 只记挣到的

墙只写这个侦探亲眼见过、选过、得过、失过、想通的。这是防剧透的纪律（别把没遇见的写进来），也是墙比存档更"真"的根源——存档是世界状态，墙是经历过的世界。

## 几个习惯

- **`Home.md` 是索引**：写清侦探是谁、走到哪了、墙里有什么。每开新页就回去更新"走到哪了"。
- **一物一页**：每个人物、每条线索、每个场景各开一页，用 `[[ ]]` 互链。墙随玩随长，连成网。
- **标记**：⭐ 重要、✅ 已结、⚠️ 存疑——给自己看的状态语言。
- **给设计师的话**写在墙末尾的反馈段（手感、卡点、哪里泄了），别写进引擎或外部记忆。

## 怎么开始

这份 `README.md` 随 `wall/` 一起复制——它就在你的墙根目录里。把 `Home.md` 的占位换成你的侦探，从 `start 1405` 的第一拍开始，照 `编年/_模板.md` 写第一页。
